# Base Prompts

These prompts borrowed from the system prompt of Roo Code. Using them as base prompts for our own system prompts within .roo files.

Roo Code isn't equal to Roo Multi Agent system which described in the README.md file. Roo Multi Agent system is based on the same tools and MCP servers, but extensivly modified to support multiple agents and a more complex system.  

 Therefore, all files at ./base-prompts must be treated as base starting points mentioned just for reference.

 You can consult with them to gather understanding of how to work with tools and which tools are present in the stock.
